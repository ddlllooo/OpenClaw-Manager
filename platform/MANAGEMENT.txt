实例管理扩展（2026-10-15）

技能与插件：原生技能状态、依赖和来源；按 Agent 查看；实例级启停；ClawHub 搜索、详情和安装。npm 插件只接受固定版本，支持安装、启停和卸载非内置插件。保留 OpenClaw 安装安全策略，不使用强制绕过。插件生命周期通过顶部“重启”应用。
模型故障切换：对话主模型、按顺序备用列表；图像分析工具主备列表。沿用 OpenClaw 原生切换和凭据冷却逻辑，不定时探测上游、不因回答质量切换。
飞书访问设置：全局和账号级私聊策略、用户白名单、群策略、群白名单、群内发送者白名单、@ 要求；单独群聊启用及提及规则；配对请求查看与批准（不发送通知）。账号凭据和高级字段原样保留。
多 Agent：原生创建、名称和模型编辑；移除只从配置名册和路由中摘除，保留工作区、凭据和会话数据库，避免 2026.9.3 原生删除墓碑导致后续网关启动失败。独立角色规则文件；飞书账号/用户/群路由。平台对话与定时任务均可选择 Agent。主 Agent、唯一 Agent、仍承担共享所有权或有定时任务的 Agent 不允许移除。

保存先检查配置版本、校验完整候选，校验后再次确认版本再写入。冲突不覆盖原数据。编辑 Agent 仅提交变更字段。管理页不回传模型密钥、飞书凭据。
创建 Agent 使用 /home/node/.openclaw/workspaces/<agentId>，位于配置持久化挂载中。共享插件存储仍遵守插件自身作用域。
新增技能安装取决于 ClawHub 可达性；第三方插件依赖和安全策略失败会显示原始脱敏错误，不视为安装成功。
