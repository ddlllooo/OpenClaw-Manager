升级成功后的自动清理（2026-10-16）

触发
实例重建/替换通过网关 readyz 检查、写入新容器及回滚指针后，登记清理任务。
随后等待 Docker 健康检查；尚在 starting、未应用配置、停止或不健康时不删除回滚版本，稍后重试。
创建但尚未启动的替换、失败升级及自动回退不触发清理。清理失败不撤销已成功的升级。
Manager 启动完成并持续健康 30 秒后登记新版本；普通重启同一镜像不轮换版本。

保留
每个实例保留最近一个回滚容器，以重命名时的回滚时间排序，不使用原容器的创建时间。
当前容器、仍在运行的回滚容器、所有实例记录及 .kept 存档引用的容器均保留。
如旧记录仍引用额外副本，优先保护引用并显示跳过，不强行实现数量上限或改写业务记录。
Manager 按确认健康的升级顺序保留当前镜像及上一版，不把尚未验证的构建当作上一版。
首次启用时可在 compose.env 中设置 MANAGER_PREVIOUS_IMAGE=<已确认的上一版镜像或完整镜像 ID>。
compose 将它传入 OPENCLAW_PREVIOUS_MANAGER_IMAGE。已有持久历史时以后按历史自动轮换。
首次启用而没有可信上一版时，不猜测、不自动删除 Manager 旧镜像。

删除范围与检查
只处理被淘汰回滚容器释放的旧运行镜像，以及同一 Manager 仓库中早于保留上一版的旧镜像。
不删除预下载的未来运行镜像、其他应用镜像或构建基础镜像；不使用全局 prune。
每次删除前重新读取全部 Docker 容器、活动/归档实例的镜像和容器引用以及 Manager 历史。
镜像仍被任何运行或停止容器引用时不删除；镜像 ID、标签归属或引用变化时跳过。
删除容器不使用 force 或 -v，删除镜像不使用 force，且启用 noprune 保留未标记的父镜像。
不删除绑定目录、卷、配置、工作区或数据库，不启动、停止或重启业务实例。

并发与结果
创建、启动、配置等平台变更执行期间暂缓清理。异步镜像拉取/创建与清理互斥。
删除的短暂窗口中，新的平台变更返回 409，可稍后重试；读取和业务网关继续运行。
Docker 不可达、记录损坏或检查失败时停止本次清理；持久任务在服务恢复后重试。
外部 Docker 客户端不受平台锁约束；最终 Docker 非强制删除仍会拒绝删除占用中的对象。
retention-state.json 保存当前/上一版 Manager、待处理任务和上次结果；retention-audit.jsonl 轮转保存审计。
数据均位于实例目录的父目录，随 Manager 容器替换保留。
本地镜像仓库显示保留规则和上次清理状态；GET /api/images/retention 返回相同状态。

清理预览与手动执行
打开本地镜像仓库后生成只读预览，分组显示将删除、将保留的镜像和回滚容器，以及逐项原因。
预览包含清理旧容器后才可删除的镜像依赖，不把镜像标称大小当作可释放空间。
预览与自动清理使用同一个计划生成器、健康检查及引用保护。预览不会推进 Manager 版本历史，也不写入清理记录。
预览令牌仅在当前管理会话和当前 Manager 进程中有效，5 分钟过期，成功使用后不可重放。
执行前检查完整计划指纹；记录引用、容器状态或镜像标签变化时返回 409，要求重新预览，删除前不产生破坏性操作。
执行过程中仍逐项重新检查引用和标签，不删除预览以外的项目，不强制删除，不移除卷或绑定数据。
容器删除失败时按实际剩余容器引用保护镜像，不依赖预览中的预计引用消失。
镜像拉取或其他实例变更执行时暂缓手动清理。检查失败时保留剩余项目并记录结果。
GET /api/images/cleanup/preview 返回预览，POST /api/images/cleanup {previewId} 执行；均受本地会话保护，执行还要求 CSRF。
旧 DELETE /api/images/:tag 返回 409，不能绕过预览和保留规则。

清理历史
本地镜像仓库支持刷新清理历史和加载更早记录，默认每页 10 次，按时间倒序显示。
记录时间、自动或手动来源、执行状态、已删除的镜像标签/ID 与回滚容器名称/ID，以及保护、跳过和失败原因。
新记录在删除前保存名称；部分标签成功移除而镜像仍存在时单独显示标签操作，不误报整幅镜像已删除。
自动重试标记为自动清理，同时保留原始任务来源。有效预览因引用变化或操作互斥被拒绝时也记录跳过原因。
GET /api/images/cleanup/history?limit=10&cursor=<上一页返回的 nextCursor>，只读且受本地会话保护。
沿用 retention-audit.jsonl 及 .1 轮转文件，每份约 1 MiB；不恢复已轮转删除的历史。日志位于持久数据目录。
兼容只有对象 ID/状态码的旧日志，明确提示未保存的名称与详细原因无法补全。
损坏或不完整的日志行跳过并提示；读取失败显示错误，不把失败伪装成空历史；分页锚点被轮转移除时要求刷新。
预览和无任务的轮询不写历史，不为展示历史连接 Docker 或执行清理。
