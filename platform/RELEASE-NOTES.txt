OpenClaw Manager 1.0.1 / 2026.10.15-fix1

修复范围
1. 统一部署版本，并公开构建及启动时间接口。
2. 恢复实例时清空旧容器 ID，正确排除自身端口并同步控制台 Origin。
3. 飞书凭据从受控原始配置读取，留空保留真实值，拒绝脱敏占位符；已有插件不重复安装。
4. .env 短值脱敏往返保持原值，敏感文件原子写入。
5. 前端请求绑定实例和页面世代，旧响应不再覆盖其他实例；会话历史也校验请求序号。
6. Docker 资源更新成功后才保存记录，停止容器也更新配额，新增容量/数值校验与 CPU/内存 0 解除限制。
7. 环境变量通过保留挂载的容器重建生效，保持镜像 digest，并保留原容器回滚。
8. 管理 API/SSE/终端使用本机会话、Host/Origin 及写请求 CSRF 校验；凭据按需读取。
9. 容器健康检查使用绝对脚本路径，HTTP 健康检查要求成功状态及预期 JSON。
10. 监控使用 one-shot 快照、有界并发和完成后调度，处理 SSE/WS 慢客户端；保留短期历史。
11. 前后端生命周期互斥，下载按镜像去重并可查询状态；操作记录脱敏元数据。
12. CLI 非零退出不再因存在 stdout 被当成成功。
13. 容器日志配置 10m x 3 轮转。
14. 镜像源、tag/digest 与创建引用保持一致。
15. 修正内存字段、CPU 配额进度、标题 HTML 和资源编辑精度。
16. 删除对话框明确区分取消、保留数据和彻底删除。
17. 配置 schema 校验、版本冲突、有限备份和失败回滚；禁止原始编辑器单独修改 Gateway Token 造成凭据不一致。
18. 停止实例返回明确 409，允许读取已存模型配置，前端禁用依赖运行状态的操作。
额外修复：终端 shell 就绪前缓存输入，断开/空闲超时后清理对应 shell。
